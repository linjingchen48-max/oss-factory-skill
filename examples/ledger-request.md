# Minimal example invocation

Use $oss-factory to build a personal ledger with income/expense entries, monthly totals,
a simple chart and local persistence. Prefer existing dependencies. No accounts, cloud,
bank integration, exchange rates or deployment. Do not install unknown repository code.
If network access is not granted, use actual installed dependencies and identify that
the selection evidence is offline, not fresh GitHub research.

Expected outcome: a runnable small application, persistence and monthly arithmetic tests,
explicit component roles and provenance, unknown licensing/maintenance details if not
verified, and a stop after those requirements pass. A custom chart is acceptable when a
charting dependency would add more complexity than value. This is a test request, not a
claim that any platform or integration has already been validated.
