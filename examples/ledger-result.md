# 离线集成示例结果

测试日期：2026-10-23。当前 Codex 会话显式读取 Skill 与参考规则后执行。
这是已安装组件的实际集成，不是真实 GitHub 搜索、生产部署或自动触发测试。

最小组合：FastAPI 0.142.2 负责 HTTP 与界面入口，Pydantic 2.13.5 负责输入验证，
Python sqlite3 负责本地保存；Uvicorn 0.54.0 负责本机服务。
版本及上游 URL 来自本机 distribution metadata；许可证字段分别声明
MIT、MIT、标准库随 Python 分发、BSD-3-Clause。未完成传递依赖法律审查。

自写逻辑只有整数分金额、收入/支出、月份边界、两条本地对比条和页面连接，
没有增加图表库、账号、队列、云数据库或私有引擎依赖。

独立示例的 9 项 pytest 检查通过，覆盖跨应用实例持久化、月度金额计算、
删除、非法金额、日期和请求合同；Ruff 检查与格式检查通过。
浏览器实际新增收入 100.10、支出 20.05，显示余额 80.05，刷新后记录保留。
这些是示例行为验证，不是对其他仓库或私有引擎历史状态的重新验收。

原生 Codex CLI 0.145.0 的项目级显式调用尝试在 90 秒超时，未收到有效执行事件。
因此原生发现、调用与自动匹配均未获通过证据；不能以目录存在或静态校验替代。
Claude Code、Cursor 仅做官方安装文档适配，没有实机运行测试。

达到上述最小示例目标后停止；独立示例源码与本地测试记录作为私有交付附件，
不打入公开 Skill 包，避免混入环境路径、运行数据和私有审计材料。
