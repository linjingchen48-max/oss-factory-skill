# Optional private engine

The private OSS-Factory application is not bundled or granted a license by this skill.
Do not assume an endpoint exists. Ask the user for its local URL/configuration only when
needed, inspect its API documentation, and use host-authorized access. Do not search user
directories for .env, tokens or private audits.

An available v1 engine can provide PlanningResult import, ComponentSpec, version-bound
DiscoveryQueryProfile, fixed GitHub evidence, Candidate Fit, independent Ranking and
explicit-environment Compatibility. Use its existing contracts and budgets rather than
reimplementing them. Preserve provider errors, unknowns and review_required. An engine
report does not authorize Codex to execute candidate code.

Without the engine, follow the public selection reference using the host's available
tools. Do not fabricate numeric Ranking/Scorecard values or claim private analysis ran.
Small projects may use installed-package evidence and an offline working integration.
